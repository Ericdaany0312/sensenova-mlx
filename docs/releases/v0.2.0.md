# SenseNova MLX v0.2.0

This release makes the formal SenseNova U1.5 text-to-image checkpoint usable as
a local MLX runtime on Apple silicon, with both one-shot CLI generation and a
persistent OpenAI Images-compatible loopback service.

## Highlights

- Formal `SenseNova-U1.5-8B-MoT` checkpoint with immutable revisions and a
  28-file SHA-256 download ledger.
- Official 8-step LoRA fast mode and base 50-step quality mode.
- MLX-only production runtime; PyTorch is confined to optional offline parity.
- Default-safe local API with Bearer authentication, input limits, supported-size
  validation, and single-GPU backpressure.
- Portable model-directory discovery through environment variables and user
  cache paths.
- Reproducible macOS unit/contract CI that never downloads formal weights.

## Verification

On an Apple M5 Max with 128 GB unified memory and MLX 0.32.1:

- 1024×1024 base, 50 steps: 85.9 seconds, 32.94 GiB MLX peak.
- 1024×1024 8-step LoRA: 25.9 seconds, 33.66 GiB MLX peak.
- 2048×2048 8-step LoRA: 44.1 seconds, 34.39 GiB MLX peak.
- Formal layer-0 cosine: 0.9999977709 for understanding and 0.9999998869 for
  generation with prefix KV cache, against a 0.999 threshold.
- Recorded swap growth: zero for all listed runs.

The complete sanitized record is included in
`docs/verification/e2e-results.json`. These are single-machine measurements and
should not be read as minimum-hardware guarantees.

## Important boundaries

- Model weights and LoRA adapters are not included in source or release packages.
- The formal download is 51,042,331,251 bytes (47.537 GiB).
- 1024×1024 is a migration smoke size outside the official quality buckets.
- Image editing, training, quantization, 4K, GUI, and ComfyUI integration are not
  included in v0.2.0.
- The local API is not a hardened public or multi-tenant service.

Project code is Apache-2.0. This independent port is not an official
OpenSenseNova release. Review the official model repository terms before use.
